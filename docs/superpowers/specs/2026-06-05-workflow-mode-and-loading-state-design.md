# 편집 방식 및 불러오기 상태 UI 설계

## 목표

- 편집 방식 선택 버튼 2개는 항상 표시한다.
- 일반 자동 작업을 선택하면 Turbo 작업 메뉴를 숨긴다.
- MoneyPrinterTurbo를 선택하면 일반 작업 메뉴를 숨긴다.
- 영상, 사진, 음악, Turbo 결과를 불러오는 동안 해당 버튼에 `불러오는 중...`을 표시하고 비활성화한다.

## 동작

- 기존 `body[data-workflow-mode]` 상태를 그대로 사용한다.
- 일반 작업 폼에 `data-workflow-panel="bird"`를 추가한다.
- CSS에서 선택되지 않은 작업 패널만 숨긴다.
- 파일 불러오기 함수는 제출 버튼의 기존 문구와 비활성화 상태를 보관한다.
- 요청 시작 시 버튼을 비활성화하고 `불러오는 중...`으로 바꾼다.
- 성공 또는 실패 후 `finally`에서 기존 문구와 상태를 복원한다.
- Turbo 결과 불러오기 버튼에도 같은 동작을 적용한다.
- Turbo 영상 생성 버튼은 생성 작업이므로 기존 `실행 중` 상태를 유지한다.

## 검증

- 일반 모드와 Turbo 모드의 상호 배타적 패널 표시를 정적 UI 테스트로 확인한다.
- 파일 및 Turbo 불러오기 버튼에 로딩 상태 처리가 포함됐는지 테스트한다.
- 전체 Python 테스트를 실행한다.
- 실행 중인 대시보드를 재시작하고 최신 정적 파일 응답을 확인한다.
